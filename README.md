# Portfolio 2026

Personal portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Focus

- Frontend development
- UI/UX design
- Responsive web publishing
- Design-to-interface implementation

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- ESLint

## Scripts

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```
